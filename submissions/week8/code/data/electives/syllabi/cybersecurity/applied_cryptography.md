Course Outline

Course Code: CS-PE-515
Course Title: Applied Cryptography
Course Type: Program Elective
Program(s): B Tech Computer Science; B Tech Computer Engineering
Year / Semester: III / V
Credits: 3 (Lecture 2, Practical 2, Tutorial 0)
Prerequisites: Discrete Mathematics

Detailed Syllabus
Unit 1  Classical ciphers, perfect secrecy, one-time pad.
Unit 2  Block ciphers (AES), modes of operation, stream ciphers.
Unit 3  Hash functions, message authentication codes.
Unit 4  Public-key cryptography: RSA, Diffie-Hellman, elliptic curves, digital signatures.
Unit 5  Applied protocols: TLS handshake, password storage, key management.
