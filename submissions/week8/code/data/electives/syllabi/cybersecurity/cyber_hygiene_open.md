Course Outline

Course Code: OE-611
Course Title: Introduction to Cybersecurity for Everyone
Course Type: Open Elective
Program(s): All UG programmes
Year / Semester: III / VI
Credits: 3 (Lecture 3, Practical 0, Tutorial 0)
Prerequisites: None

Detailed Syllabus
Unit 1  Why security matters; common threats: phishing, malware, ransomware.
Unit 2  Passwords, multi-factor authentication, password managers.
Unit 3  Safe use of networks, devices and cloud services.
Unit 4  Privacy and data protection; India's DPDP Act.
Unit 5  Responding to incidents; cyber law basics.
