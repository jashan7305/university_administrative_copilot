Course Outline

Course Code: OE-613
Course Title: Project Management
Course Type: Open Elective
Program(s): All UG programmes
Year / Semester: III / VI
Credits: 3 (Lecture 3, Practical 0, Tutorial 0)
Prerequisites: None

Detailed Syllabus
Unit 1  Project life cycle; scope, stakeholders, charters.
Unit 2  Scheduling: work breakdown structure, CPM, PERT, Gantt charts.
Unit 3  Cost estimation, earned value management.
Unit 4  Risk and quality management.
Unit 5  Agile and hybrid project management.
