Course Outline

Course Code: OE-507
Course Title: Introduction to Machine Learning
Course Type: Open Elective
Program(s): All UG programmes
Year / Semester: III / V
Credits: 3 (Lecture 3, Practical 0, Tutorial 0)
Prerequisites: Probability and Statistics

Course Objectives
1. Give students from any engineering discipline a working knowledge of machine learning.

Detailed Syllabus
Unit 1  What is machine learning; supervised and unsupervised learning; the ML workflow.
Unit 2  Regression: linear regression, regularisation, evaluation.
Unit 3  Classification: logistic regression, decision trees, k-nearest neighbours.
Unit 4  Clustering and dimensionality reduction: k-means, PCA.
Unit 5  Machine learning in engineering practice: case studies, ethics.
