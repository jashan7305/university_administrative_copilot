Course Outline

Course Code: CY-PE-722
Course Title: Ethical Hacking and Penetration Testing
Course Type: Program Elective
Program(s): B Tech Computer Science and Engineering (Cybersecurity); B Tech Information Technology
Year / Semester: IV / VII
Credits: 3 (Lecture 2, Practical 2, Tutorial 0)
Prerequisites: Network Security

Detailed Syllabus
Unit 1  Legal and ethical framework for penetration testing; rules of engagement.
Unit 2  Reconnaissance, scanning and enumeration.
Unit 3  Exploitation of web applications: OWASP top 10.
Unit 4  Privilege escalation, post-exploitation.
Unit 5  Reporting and remediation.
