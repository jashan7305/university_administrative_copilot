Course Outline

Course Code: IT-PE-613
Course Title: Network Security
Course Type: Program Elective
Program(s): B Tech Computer Science; B Tech Computer Engineering; B Tech Information Technology
Year / Semester: III / VI
Credits: 3 (Lecture 2, Practical 2, Tutorial 0)
Prerequisites: Computer Networks

Detailed Syllabus
Unit 1  Security goals, threats and attacks; the CIA triad.
Unit 2  Firewalls, intrusion detection and prevention systems.
Unit 3  Secure protocols: TLS, IPsec, VPNs, SSH.
Unit 4  Wireless and network-layer attacks; spoofing; denial of service.
Unit 5  Network monitoring, packet analysis with Wireshark, incident response.
