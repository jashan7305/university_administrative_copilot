The MPSTME library stays true to its mission of facilitating and creating new knowledge through acquiring, organizing, and disseminating knowledge resources through regular updating and providing value-added services. The library is fully automated with KOHA software. Users can login freely to a high-speed Wi-Fi network to access the e-resources. Web-OPAC, currently on the intranet, gives detailed information about library books. Users can find the real-time availability of library materials from their computer terminals. The library has an open-access system facilitating the unrestricted use of materials on the shelves. The library has a rich collection of books on management, engineering, and allied subjects and periodicals (National/International), audio-visual materials, and e-resources.
With the growing popularity of E-Resources among library users. The library provides access to various subject online databases for academic and research work.

Web OPAC
Library WEB OPAC provides a gateway to all library resources. Retrieve information through powerful, accurate, and faster search engines. MPSTME library has KOHA WEB OPAC which allows users to avail of library services online.
The collection of the library comprises books, periodicals, and e-resources. Books are arranged as per Dewey decimal classification on open shelves, and periodicals are arranged alphabetically. To browse and search for this collection, use an online catalogue (OPAC).
