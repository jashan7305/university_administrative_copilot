# Lost or Stolen ID Card: Replacement

The student or faculty ID card is required for campus entry, the library, examinations and the hostel. Report a lost card immediately so it can be blocked.

## Procedure
1. Report the loss on the student portal (ID Card > Report lost) to block the card. This prevents misuse of library and access privileges.
2. File an online lost report with the police (an FIR is required only for theft).
3. Submit form AD-07 with the lost report and one passport-size photograph at the ID Card Cell, and pay Rs. 300.
4. A temporary ID slip valid for 15 days is issued on the spot. The new card is ready in 5 working days.

## Notes
Faculty and staff apply through the Establishment Section using the same form. If you find your old card after the replacement is issued, return it to the ID Card Cell.
